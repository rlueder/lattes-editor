# Política de privacidade da extensão (rascunho)

Rascunho para a página que a Chrome Web Store exige. Ainda não publicado.

## O que a extensão faz

A extensão "LattesEditor: ponte com o Lattes" leva ao Currículo Lattes as
alterações que você fez no Editor do Currículo Lattes, usando a sessão do
Lattes que você mesmo abriu no navegador.

## Que dados ela usa

- **As alterações que você manda do editor**: o campo, o valor antigo e o
  novo, e o item do currículo a que pertencem.
- **Os formulários do seu currículo no Lattes**, lidos na sua sessão para
  conferir que o item é o certo antes de gravar e que a gravação deu certo
  depois.
- **O código do seu currículo** (10 caracteres), lido da página do Lattes e
  entregue ao editor para mostrar a sua foto.

## Para onde os dados vão

- Para o Lattes (`wwws.cnpq.br`), quando você clica em "Aplicar". É o mesmo
  envio que o formulário do Lattes faria.
- Para o editor aberto no seu navegador.
- Para nenhum outro lugar. A extensão não tem servidor, não coleta
  estatísticas de uso e não compartilha dados com ninguém.

## Onde ficam guardados

A fila de alterações fica no armazenamento de sessão da extensão e some
quando o navegador fecha. Nada é guardado em servidor.

## Uso limitado

Os dados são usados só para levar as suas alterações ao Lattes e conferi-las.
Não são vendidos, não são usados para publicidade e ninguém os lê.
